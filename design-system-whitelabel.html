Motion & Transitions

The {{PROJECT_NAME}} animation personality — two signature curves and three durations. Apply them verbatim to every interactive element.

--ease-out
cubic-bezier(.22, 1, .36, 1)

Signature expo-out — fast attack, silky settle. Entrances, drawers, reveals, hovers.

Data & Security

Trust nothing the client sends. These rules are the difference between a demo and something safe to put real users' data into.

Trust Boundary
Input & Output
Pre-Ship Security Checklist
AreaCheckWhy it matters
AuthEvery protected route/endpoint checks identity server-sideA hidden UI element is not access control
AuthorizationOwnership/role checked per-row, not just per-endpointPrevents one user reading/editing another's data
SecretsNo API keys, service roles, or tokens in client bundle or git historyLeaked keys grant full account access
InputAll user input validated and length-limited server-sideBlocks injection and malformed-data corruption
TransportHTTPS enforced, no mixed contentPrevents interception of tokens/data in transit
Rate limitingAuth, write, and expensive endpoints are rate-limitedStops brute-force and cost-abuse from one bad actor
ErrorsError responses never leak stack traces or internal detail to the clientPrevents handing attackers a map of the system

Performance & Scale

Most performance problems are architectural, not algorithmic. These are the decisions that determine whether the platform still feels fast at 100x the data — made once, early, rather than patched under pressure later.

Data Access Shape
System Shape
Complexity Sanity Check
PatternCost as data growsUse when
Indexed lookupO(log n) — stays fastAny query on a column filtered/sorted often
Paginated listO(page size) — constantAny endpoint returning a collection
Full table scanO(n) — degrades linearlyAcceptable only on small, bounded tables (e.g. a config table)
Nested loop query (N+1)O(n·m) — degrades fastNever intentionally — always the sign to batch/join
