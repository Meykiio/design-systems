Reference 07 · Architecture

Architecture

Event-sourced builds, replayable logs, typed pipelines. Every decision is auditable.

Event-Sourced Builds
Every build is a stream of typed events, replayable step by step. No black boxes.
Replayable Logs
Structured lines with timestamps, levels, and shard metadata. Filter by time or level.
Typed Pipelines
Stages declare input/output types. Mismatches fail at parse, not at runtime.
Scoped Tokens
CI tokens scoped per pipeline stage. Every use lands in the audit log.
Signed Artifacts
Every output signed and verifiable end to end. Same inputs → byte-identical output.
SLA Targets
p50 under 4 min, p99 under 10 min. Exceeded targets page on-call immediately.

Reference 07 · Engineering

Engineering Principles

Hard rules for building with this system. Non-negotiable.

Tokens
CSS Variables Only
Never hardcode colors, radii, or spacing. Always reference var(--*).
Data
Values Are Mono
IDs, commits, durations: always mono, tabular-nums, exact to the ms.
Logs
Stream Line One
First line renders under 100ms. Never batch-wait a full run before rendering.
Motion
Snap + Steps Only
.1/.2/.3s durations. State flips snap; blinks and cursors use steps(4).
a11y
AA on Near-Black
Contrast verified on #0a0f0b. Focus rings never dim below 2px solid primary.
Format
Single File
One self-contained HTML per system. No build step. Opens by double-click.
Reference 07 · Accessibility

Accessibility

AA floors hold even on near-black surfaces. Keyboard-only is a first-class use case, not an afterthought.

Focus Ring2px solid primary, 2px offset. Visible on near-black at 4.5:1 minimum.
Keyboard NavEvery action keyboard-operable. Esc closes all overlays. Tab order logical.
ARIA LabelsLog levels announce their word. Copy buttons announce state changes.
Contrast4.5:1 normal text floor on dark surfaces. Muted text (#8ba38f) passes on bg.
Live RegionsLog lines announce politely as they stream. Role="log" with aria-live="polite".
Reduced MotionBlinks and steps disable. Flip cards don't flip. Slide transitions cut to instant.
Reference 07 · Security

Build Security

Signed artifacts, scoped tokens, reproducible outputs. The UI surfaces every security event.

Signed Artifacts
Every build output signed and verifiable end to end. Verification shown in the build header.
Scoped CI Tokens
Tokens scoped per stage; every use lands in the audit log with timestamp and actor.
Supply Chain
Provenance tracked per dependency. Drift fails the build before it runs.
Reproducible Builds
Same inputs produce byte-identical artifacts. Bit-for-bit reproducibility enforced.
