Reference 01 · Engineering

Engineering Principles

Hard rules for building with this system. Never break these.

Token
Use CSS Variables Only
Never hardcode colors, radii, or spacing. Always reference var(--*).
Token
Tabular Numerals
All numeric displays must use font-variant-numeric: tabular-nums.
Layout
8pt Grid
All spacing must be multiples of 4px. Prefer 8px increments.
Motion
Respect Reduced Motion
Check prefers-reduced-motion. Disable animations when set.
Accessibility
4.5:1 Contrast
All text must meet WCAG AA. Check both themes.
Architecture
Single File
Each system is one self-contained HTML file. Zero build step.
Reference 01 · Accessibility

Accessibility

WCAG AA compliance. Keyboard navigation, focus rings, aria labels, reduced motion, contrast ratios.

Focus Ring2px solid primary, 2px offset. Visible on all interactive elements.
Keyboard NavTab order follows visual layout. Escape closes modals/dropdowns.
Aria LabelsAll buttons and links must have accessible names. Icons need aria-label.
ContrastNormal text: 4.5:1 minimum. Large text: 3:1 minimum.
Reduced MotionCheck prefers-reduced-motion. Set --dur-* to 0s when active.
Screen ReaderUse semantic HTML. Tables use th/td. Charts need text alternatives.
Reference 01 · Security

Data Security

Security-first patterns for analytics dashboards handling sensitive business data.

CSP Headers
Content Security Policy blocks XSS. Inline scripts require nonce.
Encryption
TLS 1.3 in transit. AES-256 at rest for cached analytics data.
Audit Logging
All data access logged with user, timestamp, and query hash.
RLS Policies
Row-level security on all Supabase tables. Users see only their data.

Reference 01 · Architecture

Architecture

System architecture for SaaS analytics. Data flow, caching, rendering pipeline.

Component Layer
React components with CSS custom properties. No runtime CSS-in-JS.
Token Layer
CSS custom properties in :root and [data-theme]. Zero JS for theming.
Data Layer
Supabase for data, Vercel for edge. Optimistic updates with rollback.
Cache Layer
SWR for client caching. Revalidate on focus. Stale-while-revalidate pattern.
