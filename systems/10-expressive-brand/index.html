Reference 10 · Engineering

Engineering Principles

Hard rules for building with this system. Never break these.

Token
CSS Variables Only
Never hardcode colors, radii, or spacing. Always reference var(--*).
Type
Unbounded Carries Display
Display font only for display. Body never wears the accent.
Motion
Big Springs, Few
.25/.4/.7s with overshoot. Two expressive moments per screen max.
Accessibility
AA Both Themes
Magenta text only on ink. Contrast verified light and dark.
Marquee
Pause on Hover
Every infinite animation pauses on hover and dies under reduced-motion.
Architecture
Single File
One self-contained HTML file per system. Zero build step.
Reference 10 · Accessibility

Accessibility

Loud never means illegible. WCAG AA floors, both themes.

Focus Ring3px magenta glow on all interactive elements, both themes.
Keyboard NavFull keyboard path; Escape closes overlays; marquee has a pause control.
Aria LabelsHue-morph buttons announce their action; stickers announce their text.
Contrast4.5:1 floor; accent text only on ink-dark surfaces.
Reduced MotionAll springs and marquees disabled under prefers-reduced-motion.
Type ScaleMaximum 3 display sizes per view; hierarchy via weight and space.
Reference 10 · Security

Brand Security

Protecting the brand asset itself: fonts, tokens, and content integrity.

Token Integrity
Design tokens versioned with the codebase; visual drift fails the build.
Font Licensing
Self-hosted fonts with documented licenses; no third-party CDN on brand pages.
Content Signing
Manifesto and launch content are signed; tampering is loud.
Design Review Trail
Every brand decision lands in an audit trail with its owner.
