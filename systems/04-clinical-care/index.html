Reference 03 · Security First

Security & Trust

Trust surfaces early in fintech: insurance proof, verification state, and audit transparency are first-class UI, not footers.

FDIC Insurance
Deposits insured to $250,000 per depositor. The badge links to the certificate.
256-bit Encryption
TLS 1.3 in transit, AES-256 at rest. Keys rotated every 90 days.
Real-time Alerts
Every transaction notifies within 2 seconds. Anomalies flag automatically.
Audit Trail
Every account action is logged, immutable, and exportable by the customer.

Reference 03 · Accessibility

Accessibility

Banking must work for everyone. WCAG AA is a floor, not a goal.

Focus Ring3px primary ring on all interactive elements, both themes.
Keyboard FirstFull flows operable by keyboard. Enter submits, Escape cancels.
Aria LabelsAmounts announce with currency. Status changes are live regions.
Contrast4.5:1 normal, 3:1 large. Verified on mint-tinted and dark surfaces.
Color IndependenceSigns and labels carry meaning; color never stands alone.
Error CopyErrors say what happened, why, and the exact next step.

Reference 03 · Architecture

Architecture

Banking stack: ledger-first data model, strong auth, audited actions.

Ledger Core
Append-only, double-entry ledger. Balances are derived, never stored mutable.
Event Sourcing
Every transaction is an immutable event with a full audit chain.
Auth Layers
MFA mandatory. Device binding, step-up auth on sensitive actions.
Realtime Push
Transaction websockets deliver alerts under 2 seconds end-to-end.
