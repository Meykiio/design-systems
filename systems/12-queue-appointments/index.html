Animation

Motion

Everything moves like a departures board: sharp start, precise landing. The spring is reserved for the status-line indicator -- the one element that physically tracks a state change.

--ease-out
cubic-bezier(.22,1,.36,1)

The primary curve. Fast attack, precise settle. Used on page transitions, the board row state change, card reveals, and drawer open/close.

--ease-spring
cubic-bezier(.34,1.22,.64,1)

Light overshoot for micro-feedback. The nav indicator, chip dismiss, and the board status-line sliding to its new row. Never use on anything that moves more than 80px.

Durations
--dur-fast: .15s

Fast (.15s) -- hover, icon switch, chip dismiss. Med (.26s) -- card lift, focus ring, form validation. Slow (.48s) -- page slide, sidebar collapse, board row transition.

Adaptability

Responsive Behavior

Mobile-first. Most customers join from a phone. The departures board collapses to show number, name, and status only -- ETA disappears below 640px.

BreakpointWidthKey behavior
Mobile< 640pxBoard drops ETA column; single column layout; 16px margins; bottom-sheet modals
Tablet640-1023pxSidebar becomes off-canvas drawer; 2-col card grid collapses to 1
Desktop1024-1440pxFull sidebar; board at 680px max-width; queue + booking side by side
Wide> 1440pxContent capped at 1080px; sidebar collapses to icon rail
  • Queue numbers are always the largest element on screen, any breakpoint
  • RTL is layout-level: status line flips to the right edge in Arabic mode
  • TV display mode: queue number at 120px, board fills viewport, no sidebar
  • Safe area insets applied via env(safe-area-inset-*) on all fixed elements
