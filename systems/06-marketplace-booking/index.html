Reference 06 · Engineering

Engineering Principles

Hard rules for building with this system. Never break these.

Token
CSS Variables Only
Never hardcode colors, radii, or spacing. Always reference var(--*).
Money
Prices Are Mono
All nightly rates and totals use --font-mono with tabular figures.
State
Lock Holds
Selected dates hold for 10 minutes with a visible countdown.
Motion
Confident Glides
Out-quint, circ, soft-spring. No hard bounce on booking actions.
Accessibility
AA Both Themes
Contrast verified in dark and light; focus rings never suppressed.
Architecture
Single File
One self-contained HTML file per system. Zero build step.

Reference 06 · Architecture

Architecture

Two-sided stack: inventory service, hold locks, escrow flow.

Inventory Service
Availability computed server-side; the calendar is a projection, never the source.
Hold Locks
Selected dates hold 10 minutes server-side with visible countdown.
Escrow Flow
Charges capture after host acceptance; releases 24h after check-in.
Edge Cache
Listings cached at edge; invalidation on calendar change within 60s.
