Reference 05 · Engineering

Engineering Principles

Hard rules for building with this system. Never break these.

Token
CSS Variables Only
Never hardcode colors, radii, or spacing. Always reference var(--*).
Realtime
Optimistic UI
Mutations render instantly, rollback on failure. Never await the wire.
Layout
Reserve Space
Avatars, media, and rows reserve exact dimensions. Zero reflow.
Motion
Springs Under 450ms
Back-out for taps, in-out for sheets, out-quad for hover.
Accessibility
AA Both Themes
Contrast verified in dark and light. Live regions announce updates.
Architecture
Single File
One self-contained HTML file per system. Zero build step.

Reference 05 · Security

Social Security

Safety patterns for realtime social: blocking, moderation, data dignity.

Block & Mute
Instant, silent, and complete. Blocked users never appear in any feed or room.
Moderation SLA
Reports triaged in 24h. Live rooms carry an always-present flag action.
Data Dignity
One-tap data export, one-tap delete, honored within 24 hours.
E2E DMs
Direct messages are end-to-end encrypted; keys never leave the device.

Reference 05 · Architecture

Architecture

Realtime stack: websockets, optimistic cache, presence service.

Socket Layer
Single multiplexed websocket; typing, presence, and messages share one channel.
Optimistic Cache
Local-first mutations with rollback; reconciliation on socket ack.
Presence Service
Heartbeat-based liveness with 10s expiry; away state on idle.
E2E Envelope
DMs sealed client-side; server stores only ciphertext.
