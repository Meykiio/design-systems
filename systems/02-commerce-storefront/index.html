Reference 02 · Engineering

Engineering Principles

Hard rules for building with this system. Never break these.

Token
CSS Variables Only
Never hardcode colors, radii, or spacing. Always reference var(--*).
Token
Prices Are Mono
Every price uses --font-mono with tabular-nums. No serif or body-font prices.
Layout
Image Ratio Lock
Product card media is locked 1:1. The gallery's main image is locked 4:3. Never let either shift during load.
Motion
Respect Reduced Motion
Check prefers-reduced-motion. Disable spring animations when set.
Accessibility
AA Contrast Both Themes
All text meets WCAG AA in light AND dark. Verify sale badges too.
Architecture
Single File
One self-contained HTML file per system. Zero build step.
Reference 02 · Accessibility

Accessibility

WCAG AA compliance for commerce: focus, labels, contrast, reduced motion, screen readers.

Focus Ring4px primary glow ring, visible on every interactive element in both themes.
Keyboard NavTab follows visual order. Escape closes cart drawer and mobile menu.
Aria LabelsFav buttons announce add/remove. Bottom-nav tabs have accessible names.
Contrast4.5:1 normal text, 3:1 large. Verified against cream and charcoal backgrounds.
Reduced MotionSprings become instant transitions when prefers-reduced-motion is set.
Screen ReaderProduct cards are one article element. Prices are text, never images.
Reference 02 · Security

Storefront Security

Checkout integrity, customer data protection, and fraud prevention patterns.

PCI-DSS Flow
Card data never touches our servers. Tokenized via payment provider only.
Session Security
HttpOnly, Secure, SameSite cookies. Cart survives hours, not secrets.
Fraud Signals
Velocity checks and address verification run server-side, invisibly.
Privacy by Default
Minimal PII at signup. Data export and delete requests honored in 24h.

Reference 02 · Architecture

Architecture

Storefront stack: edge-rendered pages, client cart, payment tokens.

Edge Render
Product pages are statically generated with edge revalidation on inventory change.
Client Cart
Bag state lives in localStorage, synced to server on auth. Optimistic mutations.
Payment Tokens
Provider-side tokenization. Card fields hosted; PCI scope stays minimal.
Image CDN
On-demand resize and format negotiation per device. Ratio locked in markup.
