Reference 08 · Engineering

Engineering Principles

Hard rules for building with this system. Never break these.

Token
CSS Variables Only
Never hardcode colors, radii, or spacing. Always reference var(--*).
Type
Serif First
Newsreader owns display and body; mono only for metas.
Layout
72ch Measure
The reading column is capped at 72ch; margins are generous.
Motion
Quiet Curves
.15/.3/.6s, in-out-sine or linear. No springs near prose.
Accessibility
AA Both Themes
Warm off-white on warm charcoal at night; paper cream by day.
Architecture
Single File
One self-contained HTML file per system. Zero build step.
Reference 08 · Accessibility

Accessibility

WCAG AA for long-form reading, both themes.

Focus Ring3px ink or gold ring on all links and controls, both themes.
Keyboard NavFull keyboard reading. Footnote markers are focusable buttons.
Aria LabelsFigures carry aria-labels; captions are real text nodes.
Contrast4.5:1 floor for prose; never below, even in captions.
Text ZoomLayout survives 200% text zoom without horizontal scroll.
Motion SafeAll transitions disabled under prefers-reduced-motion.
Reference 08 · Security

Reader Security

Privacy-respecting reading: no tracking, anonymous-first comments.

No Trackers
Zero third-party scripts on reading pages. Analytics is first-party only.
Comment Dignity

HTTPS Only

Export Everything
